# Mateus Aguiar — Personal Trainer & Consultoria

Página institucional (single-page) do personal trainer Mateus Aguiar, com planos,
serviços e contato direto via WhatsApp.

## 🚀 Publicação

Site estático (HTML/CSS/JS puro, sem dependências) hospedado no **GitHub Pages**.

## 📁 Estrutura

```
index.html          Página principal
assets/
  logo.jpeg         Logo da marca
  mateus.jpg        Foto do personal
```

## ✏️ Como editar

- **Preços / planos / textos:** direto no `index.html`.
- **WhatsApp:** número e mensagem padrão no bloco `<script>` (variáveis `WA_NUMBER` e `WA_MSG_DEFAULT`).
- **Imagens:** substitua os arquivos em `assets/` mantendo os mesmos nomes.
